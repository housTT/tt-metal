Method

Replicates the media server's TTS benchmark client (utils/media_clients/tts_client.py) against the live P150 server: 10 sequential calls, concurrency 1, response_format:"json". Latency = time to full response; RTR = audio duration ÷ processing time; percentiles by the harness's index method. Sweep: 5 warm reps per length.

Scope

This benchmarks the serving path in use: the plbert transformer runs on the P150; the StyleTTS2 predictor and ISTFTNet vocoder run on the host CPU. The all-on-device vocoder is validated separately but not yet wired into the server, so latency here is bounded partly by host-side vocoding.
