# Inherited device contract for optimized vLLM

This source/artifact audit applies the [optimize checklist](../../../../../.agents/skills/optimize/SKILL.md)
to the orchestration-only scope in the [current topology audit](work_log.md#operation-topology-audit).
The adapter passes the selected precision configuration to the existing generator
([source](../../tt/generator_vllm.py)); this stage preserves decoder arithmetic,
tensor layouts, kernels, collective topology, and precision. No hardware run,
model import, or profiler collection was performed for this review.

All include model, final norm, LM head, sampling and device feedback; zero timed token readbacks/synchronizations. The selected unchanged device path is sufficiently characterized to investigate
adapter trace lifetime, page-table copies and token-return overhead. This audit
does **not** certify a new exhaustive decoder optimization sweep. Acceptance of
the current change still rests on the candidate's focused correctness probes,
normal shutdown/reopen proof, and final primary 128/128/1 plus CI 100/100/32
serving measurements and qualitative/sampling checks.
