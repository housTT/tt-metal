The finding that matters — why the agentic scores are 0

Thinking-mode × batch-1 = a per-step throughput wall. With reasoning enabled, a single agent step generates a long chain-of-thought, often up to the output-token cap. At the served batch-1 rate (~25 t/s/u), that is minutes of decode per step: with SWE's 32k cap, one deep step ran ~22 minutes — astropy-12907 froze at step 45 and the 40-min budget expired with 0 instances done. Dropping Terminal-Bench's cap to 4096 made the agent step through the whole run actively, but deep-context steps are still slow enough that the 30-min task timeout arrived mid-generation.
Mitigation: cap per-step max_output_tokens (4096 kept the agent moving vs. frozen). Bigger levers for a real agentic pass: raise served decode throughput (spec-decode — feasibility proven but eager is break-even; traced needs the trace-coexistence fix), or run with reasoning trimmed for tool-use turns. Single-turn code (HumanEval) is unaffected — completions are short.
Thinking leaks into /v1/completions output. The deepseek_r1 reasoning parser only runs on the chat endpoint; raw completions return the model's reasoning verbatim, so some HumanEval misses are CoT-in-the-code (syntax errors), not wrong logic — hence the separate thinking-off chat re-run above, which is the fair number.
