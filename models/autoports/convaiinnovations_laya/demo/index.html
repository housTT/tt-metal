Laya: one forward pass, typed answers, calibrated probabilities

Laya is a 421M-parameter decision model published by convaiinnovations: a ModernBERT-large encoder with a decision head. It is not a language model and never generates text. You give it a state (an email, a ticket, a log, JSON) and typed questions: choice (pick one label), score (an ordinal level), noul (true or false). One forward pass returns a calibrated probability for every option, in about 11 ms per single-question call on this chip.

It is made for the small decisions inside agents and workflows: routing, triage, escalation gates, moderation and scoring, where a calibrated number is worth more than a generated paragraph. The authors ship it zero-shot and report that fine-tuning on your own decisions is where accuracy jumps. This page talks only to the public API of the server that serves it: POST /v1/systemone, POST /v1/systemone/batch and GET /v1/health.
