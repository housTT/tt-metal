One forward pass, typed answers, calibrated probabilities

Laya is a ModernBERT-large encoder with an option-scoring head (421M parameters). It never generates text. You give it a state (text or JSON) and typed questions: choice (pick one of several labels), score (an ordinal level), noul (true or false). Every question comes back with a probability over its options, a confidence, and the model's own escalation signal. This page talks only to the public API of the server that serves it: POST /v1/systemone, POST /v1/systemone/batch and GET /v1/health.
