## Residual Risk

- Decision-level correctness on the device is still unproven: stages 1 to 3 gate hidden-state and logit PCC, and the probability-level gates (confident agreement >= 98 percent, median max |dp| <= 0.02) belong to stage 6. The content-dependent per-layer loss after layer 19 (0.983 at B 2, per row down to 0.9941 after the final norm) is the main risk to that gate; the erf GELU closed most of it for the fill row alone but not inside the B 2 batch.
- The sharded GeGLU path (buckets 2 and 4) has the weakest evidence of all buckets: no tracked replay run, no end-to-end marker PCC, and placement decisions inside the measurement scatter. The deployment process will capture all seven buckets at once, which no run has done yet.
- All performance numbers were taken on a host shared with three CPU tracks; 12 A/B cells sit at loads of 9.3 to 10.5 and the shipped B 2 / 4 / 16 / 32 cells at 8.0 to 8.2. Device-bound buckets are robust to this; B 1 numbers carry about 5 percent uncertainty.
- The evaluation harness has been validated against CPU servers only. The device-specific headers (`X-Laya-Device-Ms`, `X-Laya-Batch`) are exercised only by the mock package server.
- `tt/engine.py` (the `LayaEngine` the server and the shim import) does not exist yet; the server contract in the serving README is a promise to Track T2, not tested code.
- Both manifests still carry `PLACEHOLDER` values and were validated offline only.
