Cloudflare/clef on Tenstorrent

Clef is Cloudflare's 27B open-weights decision model, post-trained from Qwen3.8-27B. It does not write text. You give it a state (a document, a JSON record, a ticket, an image or video frames) and a schema of typed questions: choice over named options, yes/no, or a score on an ordered scale. In one forward pass it returns a calibrated probability for every allowed option of every question, so there is nothing to parse and no sampling. It is built for the decisions around an agent or a workflow: routing a message to a team, classifying an intent, deciding whether a policy applies, picking a tool, scoring urgency, judging an image. Cloudflare's announcement explains the design and the benchmark suite: Clef decision models on the Cloudflare blog. This page talks to that model running on two Tenstorrent Blackhole chips.

One request, several decisions at once: choice, yes/no (noul) and score questions over one state, text or image, answered by the Clef joint schema head served from two Blackhole chips (TP=2).
